# Redshift distancing
Using [[Redshift]] phenomenon, we can measure spectrum lines from distant galaxies and determine the redshift during the photon travel. however there are 3 types of distances in dealing with different scenarios. This is because the space is not Eucledian but we still use a Eucledian intuition to define these coodinates.

We can introduce the definition of distance from the photon trajectory:
- [[Comoving distance]]
- [[Comoving Angular distance]]
- [[Luminosity distance]]

> [!NOTE] The three Distances are all Larger in an $\Omega_\lambda$ Universe
> For fixed $H_0$, it takes longer for the univsers to contract to a certain scale factor. This maskes $d_L(a),\chi(a),d_A(a)$ to increase.
