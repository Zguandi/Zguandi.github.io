# Class 0
Smeared blackbody. Meaning proto star+Envelope structure. First step of planet formation.
# Class I
Smeared blackbody with absorption lines.
Meaning Protostar + Envolope + disk
# Class II
Smeared Blackbody
Meaning Star + Disk
# Class III
Marginally smeared  blackbody.
meaning Devris disk with only dust.
Last phase of evolution.
