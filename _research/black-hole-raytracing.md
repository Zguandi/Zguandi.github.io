A primitive code written for black hole ray tracing, written in Python. This project implements numerical solutions to the geodesic equations in Schwarzschild spacetime.

## Overview

This research project focuses on visualizing the gravitational lensing effects around black holes by tracing light rays through curved spacetime.

## Key Features

- Numerical integration of geodesic equations
- Visualization of light bending around black holes
- Customizable initial conditions and observer positions

## GitHub Repository

The code is available at [General Relativity Lensing](https://github.com/Zguandi/General_Relativity_Lensing).
